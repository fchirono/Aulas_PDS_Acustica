	\section{Revisão}
	\subsection{Periodograma}
	
	Seja $x[n]$, $n = 0, \ldots, N-1$ uma sequência de tempo discreto. O periodograma é a estimativa espectral obtida a partir da DFT normalizada de um único segmento (ou ``quadro'') de comprimento $N$ desta sequência, aplicando-se opcionalmente uma janela $w[n]$:
	
	\begin{equation}
		X_w(\Omega) = \sum_{n=0}^{N-1} w[n] x[n] e^{-j \Omega n}.
	\end{equation}
	
	Diferentemente do estimador de Welch (ver Tutorial 10), o periodograma \textbf{não} reduz a variância da estimativa conforme a quantidade de dados analisados aumenta: ao aumentar o comprimento $N$ do sinal analisado, a resolução em frequência $\Delta f = f_s / N$ melhora (i.e. diminui), mas a variância da estimativa permanece constante. Como consequência, o periodograma não converge para a Densidade Espectral de Potência teórica do sinal conforme mais dados são adicionados. Esta limitação do periodograma motivou o desenvolvimento do método de Welch.
	
	% *-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-
	\subsection{Normalizações do Espectro de Potência e da Densidade Espectral de Potência}
	
	Para uma sequência $x[n]$ de comprimento $N$, janelada por $w[n]$, e com fatores de normalização de janela $S_1 = \sum_{n=0}^{N-1} w[n]$ e $S_2 = \sum_{n=0}^{N-1} w^2[n]$, as duas normalizações possíveis do estimador (periodograma ou Welch) são:
	
	\begin{itemize}
		\item \textbf{Espectro de Potência} (\emph{Power Spectrum}, PS): estima a \emph{potência total} contida dentro de cada ``bin'' em frequência. A PS resulta em estimativas consistentes para a potência (e portanto, para a amplitude) de sinais deterministicos (e.g. sinais senoidais), independentemente do comprimento $N$ usado:
		\begin{equation}
			PS(\Omega) = \frac{2}{S_1^2} \left| X_w(\Omega) \right|^2;
		\end{equation}
		
		Para um sinal $x[n]$ em Volts ($V$), o seu Espectro de Potência terá unidades $V^2$.
		
		\item \textbf{Densidade Espectral de Potência} (\emph{Power Spectral Density}, PSD): estima a \emph{densidade de potência} -- isto é, potência total dividida pela largura de banda de cada ``bin'' em frequência. A PSD resulta em estimativas consistentes para a densidade espectral de potência de sinais não-deterministicos (e.g. ruído), independentemente do comprimento $N$ usado:
		\begin{equation}
			PSD(\Omega) = \frac{2}{f_s S_2} \left| X_w(\Omega) \right|^2.
		\end{equation}
		
		Para um sinal $x[n]$ em Volts ($V$), a sua Densidade Espectral de Potência terá unidades $V^2 / Hz$.
		
	\end{itemize}
	
	Ambas as expressões definem um espectro unilateral (isto é, apenas de $f=0$ a $f_s/2$, descartando as frequências negativas), e o fator ``2'' é usado para preservar a potência total do sinal.
	
	A potência de um sinal dentro de uma faixa de frequências pode ser obtida pela \emph{soma} dos valores do seu Espectro de Potência dentro desta faixa, ou pela \emph{integral} -- isto é, levando em consideração a resolução em frequência $\Delta f$ -- da Densidade Espectral de Potência dentro desta faixa de frequências.

Filtre este sinal usando um filtro passa-faixas Butterworth de 4\textsuperscript{a} ordem, com frequências de corte $f_{c,baixa} = 50$ Hz e $f_{c,alta} = 2000$ Hz, obtendo o sinal {\tt x\_passafaixa}. O projeto de filtros em Python é assunto de um tutorial futuro; para este tutorial, siga o exemplo abaixo:
		
		
		\begin{lstlisting}[frame=single]
import numpy as np
import scipy.signal as ss

# cria uma instancia do Gerador de Numeros Aleatorios do modulo Numpy
rng = np.random.default_rng()

# cria uma serie temporal de numeros aleatorios com distribuicao gaussiana,
# com media 0.0, desvio padrao 1.0, e (T*fs) amostras.
x_ruidobranco = rng.normal(loc=0.0, scale=1.0, size=int(T*fs))

# Cria o filtro passa-faixas
fc_baixa = 50  		# Hz
fc_alta = 2000  	# Hz
ordem = 4

# cria filtro passa-faixa
b, a = ss.butter(ordem, [fc_baixa, fc_alta], btype='band', fs=fs)

# Filta o sinal ruido branco para obter um sinal de banda limitada
x_passafaixa = ss.lfilter(b, a, x_ruidobranco)
		\end{lstlisting}
